# Smart Space Occupancy Detection Using PIR Sensor

## Description
This project detects human motion using a PIR sensor and automatically controls an LED using Arduino UNO.

## Components
- Arduino UNO
- PIR Sensor
- LED
- Resistor

## Working
When motion is detected:
- LED turns ON

When no motion:
- LED turns OFF

## Simulation
Implemented using Wokwi Simulator.
